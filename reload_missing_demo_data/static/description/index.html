Reload Missing Demo Data

This module provides an easy way to reload demo data for installed Odoo modules without reinstalling them. It helps developers and administrators quickly restore or refresh demo records for testing and configuration purposes.

✨ Key Features

  • Reload demo data for all installed modules with a single action.
  • Option to reload demo data for a specific module only.
  • Automatically handles module dependencies to ensure proper loading order.
  • Displays logs and results directly in the session record for easy tracking.

⚡ How It Works

  • Go to Settings → Technical → Actions → Reload Demo Data Session.
  • Create a new session and specify the module name (optional).
  • Click button Trigger — the system will automatically reload demo records and post logs to the chatter (if something wrong).

🏆 Benefits

  • Quickly refresh demo data for testing or training environments.
  • Avoid full module reinstallation and save development time.
  • Keep demo environments consistent and up to date.
Ideal for developers, QA teams, and functional testers who frequently need to reload or restore demo data during development and configuration.
